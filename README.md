Номер у загальному списку студентів — **67**. У лабораторній №2 є 10 зразків. За формулою викладача зі с. 9 `lect0-process-2026.pdf`:

```text
(67 - 1) % 10 + 1 = 7
```

Тому для обох завдань обрано **зразок №7**, а в кольорах таблиці `nn = 07`: `#078f8f` і `#f5f507`.

**Репозиторій:** https://github.com/coffer-45/frontend-lab2-css

## Запуск

Відкрийте `index.html` у браузері. Сторінка статична: інсталяція пакетів і сервер не потрібні. Шрифти завантажуються з Google Fonts; без інтернету відображаються системні замінники.

## Реалізація

- `index.html` — таблиця за формою зразка №7, обидві фігури та вбудований CSS **лише для таблиці**. Перші два рядки мають по три окремі комірки з відповідними даними й перемикають фони через `:hover`. Для форми зразка використано `colspan`, `rowspan` і додаткові порожні комірки. Верхню ліву зону візуально об'єднано без спільної HTML-комірки: це дозволяє зберегти окремі комірки даних у кожному з двох рядків, як вимагає текст завдання.
- `style.css` — оформлення сторінки й **обидва CSS-зображення**. У першій фігурі деталі розміщено через `position`, у другій — за допомогою CSS Grid та `transform` без `position` для деталей. Файлів зображень для малюнків немає.
- `page-screenshot.png`, `table-screenshot.png`, `figures-screenshot.png` — скриншоти сторінки та завдань для звіту.
- `lab2.typ` — вихідний файл звіту; `lab2.pdf` — готовий звіт.

Текст таблиці має контраст не нижче 4.5:1 для обох фонів (`#071414` на `#078f8f` — приблизно 4.77:1, на `#f5f507` — приблизно 16.04:1). Підхід до перевірки описано в [Adobe Color Contrast Checker](https://color.adobe.com/create/color-contrast-analyzer).

Для оновлення PDF-звіту (якщо встановлено Typst): `typst compile lab2.typ lab2.pdf`.
